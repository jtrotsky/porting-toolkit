# <APP> — FreeBSD daemonless image

This repo builds a FreeBSD OCI image for [<app>](<upstream URL>) using `dbuild`.

## Quick reference

- `/port-package` — full porting workflow (research → build → CIT → PR)
- `/bump-upstream` — bump pinned upstream version and re-validate
- Cookbook: `.claude/reference/freebsd-porting-cookbook.md` — check here BEFORE guessing at errors
- Build notes: `BUILD-NOTES.md` — FreeBSD-specific changes and rationale

## Rules

- **Edit `Containerfile.j2` only** — the `Containerfile` is generated by `dbuild generate`
- **Build only via `scripts/build.sh`, always backgrounded** (`run_in_background: true`) — foreground builds get SIGKILLed at the tool timeout; a hook blocks them. The script greps `build.log` for real errors (exit 0 ≠ success)
- **A green build ≠ a working image** — `scripts/cit-with-logs.sh` must pass (CIT **and** the `scripts/smoke-test.sh` functional probe)
- **Pin upstream release tags** — never build `main`
- **Branch off `upstream/main`** for PRs — keep the diff clean
- Run `scripts/lint-compose.sh` before committing to catch metadata mismatches and quality-floor violations
- **No PR until `port-auditor` returns CLEAN** — every non-boilerplate line must trace to the brief, a cookbook entry, or a logged error
